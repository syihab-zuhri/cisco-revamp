# Eval: Discovery Basic

Input: ide aplikasi baru yang masih kasar, tanpa repo atau screenshot.
Fakta tersedia: hanya brief user.
Expected mode: DISCOVERY. Expected gate: CANDIDATE_GATE_A.
Output wajib: handshake v5.1, facts/constraints/assumptions/open questions, P0/P1/P2, risks, manifest, approval state.
Terlarang: blueprint lengkap, mengarang vendor/angka, menyatakan Gate B approved.
Failure: tidak bertanya blocker atau menyatakan implementation ready.
