# Eval: Change Request

Input: permintaan mengubah fitur P0 pada proyek Approved.
Expected mode: CHANGE_REQUEST.
Output wajib: klasifikasi, impact analysis, authoritative-first update order, affected IDs/documents, permission/migration/test impact, changelog plan, conflict record bila perlu.
Terlarang: menambah P0 diam-diam atau mengubah Approved tanpa owner/reason.
